# isaac-site

Este site é uma wikipedia simples sobre o jogo **The Binding of Isaac: Rebirth**, somente com o conteudo dos peronagens do jogo.

**Site publicado:** https://epog772.github.io/isaac-site/index.html

## Sobre

Escolhi este jogo como tema porque é um jogo que jogo bastante.

## O que tem no site

- Página inicial com todos os personagens listados, com links clicáveis para as suas respectivas páginas.
- Uma página para cada personagem, com as estatísticas básicas e os itens iniciais (se tiver).
- Uma página para cada versão Tainted dos personagens.
- Um botão, na página de cada personagem, que leva para a sua versão Tainted, e outro botão na página Tainted para voltar ao personagem normal.

## Tecnologias

- HTML
- CSS
- Git e GitHub Pages

## Estrutura do repositório

```
index.html       página inicial
style.css        estilos do site
personagens/     páginas dos personagens
README.md        este arquivo
RELATORIO.md     relatório de aprendizagem
```

## Como ver o site

Abra o link do GitHub Pages acima, ou baixe o repositório e abra o `index.html` no navegador.
